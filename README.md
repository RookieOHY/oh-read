# oread

本地优先的跨平台阅读器。目标：EPUB / PDF / TXT / 漫画 / 网络小说统一阅读。

当前技术栈（MVP）：Tauri v2 + Vite + React + TypeScript + foliate-js。

## 核心设计约束

以下三点是所有实现必须遵守的硬性要求。

### 1. 内存优先

- 书页图片按显示尺寸解码，不加载原图；配合 LRU 缓存（当前页 ±1 页），离开视口立即释放。
- 章节懒加载 + 及时卸载，避免整本书一次性进内存；使用 foliate-js 的 `section.unload()` 与 `URL.revokeObjectURL()`。
- 书架元数据与阅读进度使用轻量读取，不做全量常驻缓存。
- 禁止无界增长：任何缓存必须有上限与淘汰策略。

### 2. 打开 / 关闭速度

- 冷启动只初始化必要模块，渲染器与重型依赖按需加载。
- 书籍文件随机访问（zip.js 流式解压），不预解压整本书。
- 关闭时释放所有 blob URL、章节资源与 WebView 引用，避免残留进程。

### 3. UI 参考 Apple Human Interface Guidelines

- 使用系统字体栈（`-apple-system`, SF Pro），不引入与系统冲突的字体。
- macOS 标准布局：侧边栏 + 内容区、标准工具栏；为红黄绿窗口按钮预留区域。
- 支持深色模式、系统强调色、毛玻璃（vibrancy）效果。
- 遵循 8pt 间距网格与标准圆角；动画克制，尊重"减少动态效果"系统设置。
- 支持系统级快捷键（Cmd+O 打开、Cmd+W 关闭、Cmd+, 设置等）。
